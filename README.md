# workout_tracker_2026

SeSAC 용산캠퍼스 플러터 앱 개발 과정에서 진행하는 실습 프로젝트입니다. 운동 기록을 관리하고 추적하는 기능을 제공합니다.

---

## 주요 기능
본 프로젝트는 다음과 같은 3가지 핵심 모듈로 구성됩니다.

- **운동 프로그램**: 체계적인 운동 계획 및 프로그램을 제공합니다.
- **회원 관리**: 사용자 인증 및 프로필 관리를 수행합니다.
- **나만의 운동**: 개인화된 운동 루틴을 생성하고 기록합니다.

---
